# Centro Espírita Discípulos de Jesus
Site institucional estático feito com HTML, CSS e JavaScript puro.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub (ex.: `centro-espirita-discipulos-de-jesus`).
2. Extraia este ZIP no computador.
3. No repositório, clique em **Add file > Upload files**.
4. Envie `index.html`, `style.css`, `script.js` e a pasta `assets` com todas as imagens.
5. Clique em **Commit changes**.
6. Abra **Settings > Pages**. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)` e clique em **Save**.
7. Aguarde a publicação. O endereço aparecerá nessa tela, normalmente `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Antes de divulgar
O bloco Contato está sem endereço e telefone porque os dados oficiais ainda precisam ser confirmados. Edite `index.html` e substitua o conteúdo de `<section class="contact" id="contato">` pelos dados oficiais. Para WhatsApp, use `https://wa.me/55DDDNUMERO` (somente números, com código do Brasil e DDD).

## Arquivos
- `index.html`: conteúdo e estrutura.
- `style.css`: identidade visual e responsividade.
- `script.js`: menu para celular e ano automático.
- `assets/`: fotos fornecidas para o projeto.
